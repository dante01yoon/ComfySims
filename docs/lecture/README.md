# 강의 자료 — "에이전트에게 집을 짓게 하는 법" (roomfit 제작기)

나중에 강의를 찍을 때 바로 쓰도록, 2026-10-18 하루 동안 roomfit을 만든 과정을 장면·증거·숫자로 정리한다. 원본 기록은 [저널](../journal/2026-10-18-session-01-harness.md)(세션 01~17, 강의 포인트 1~30), [구현 세션 녹화](../recordings/), [ADR](../adr/), [스펙](../../spec/).

## 한 줄 메시지

> 에이전트에게 일을 시키기 전에 **채점기(하네스)와 시험지(스펙)** 를 먼저 만든다. 그러면 에이전트는 스스로 검증하고, 막히면 우회 대신 보고한다. 사람은 스펙을 쓰고, 녹화를 보고, 반복되는 실수를 구조로 막는다.

## 촬영 메모

- 라이브로 보여줄 것: 스펙 세션 하나(AC 표 쓰기 → verify 빨간불), 헤드리스 구현 세션 하나(녹화 재생), verify 표.
- 화면 녹화가 이미 있는 것: 데모 영상 5개, 세션별 transcript(`.recordings/*.jsonl`, 로컬).
- 아직 없는 것: AC-76(로컬 모델 필요), M7, SDD 도구 비교 실험(`exp/sdd-baseline`), poteto-mode 켬/끔 비교.
- 질문 대비: "구현 세션이 왜 다 한 번에 통과했나?" → 스펙이 작고 시험지가 구체적이며 verify를 에이전트가 먼저 돌림. "BLOCKED가 왜 다 사람 탓인가?" → 시험지 보호가 사람 실수를 드러내는 장치가 됐기 때문.
