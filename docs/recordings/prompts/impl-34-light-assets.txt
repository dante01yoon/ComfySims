spec/M16-light-assets-no-stalls.md (Approved) 의 빨간 AC들(AC-125~AC-130, AC-132, 타입 검사 포함)과 M15의 AC-133을 초록으로 만들어줘. 핵심은 ADR-0014야: 생성된 GLB를 피팅 단계에서 먼저 최적화하고(weld → meshoptimizer simplify 25k 삼각형, 오차 ≤ 크기의 0.5% → prune/dedup → 텍스처를 최대 치수 100cm 이상이면 1024², 아니면 512²로 줄이고 WebP(EXT_texture_webp)로) 그 다음에 정렬·피팅해. packages/fit에 optimizeGlbBytes와 ResizeImage 타입을 만들고 fitGlbBytes의 optimise 옵션을 붙여. 브라우저에서는 이 작업 전체를 Web Worker(web/src/fit.worker.ts, OffscreenCanvas로 리사이즈·인코딩)에서 하고, 메인 스레드는 fitGlbBytes를 직접 부르지 마(renderStats().mainThreadFits = 0). IndexedDB 캐시(clearAssetCache), 프레임당 텍스처 업로드 2개 이하, 에디터↔스튜디오 전환 시 캔버스 크기 유지, 스튜디오 셰이더 미리 컴파일(compileAsync), 360°·3D 사진 뷰어 lazy chunk(파일명 panorama-viewer-*, photo-viewer-*), 라이브러리 썸네일을 React 렌더 밖 큐에서 프레임당 하나씩 그려 asset.thumbnail에 저장, renderStats 확장과 assetStats, 작업 카드의 'optimising' 단계를 구현해. M15 AC-133은 걷기 모드에서 하단 바의 키 안내 문구가 한 단어씩 줄바꿈되며 바가 세로로 커지는 결함이야. 테스트용 무거운 GLB는 fixtures/glb/heavy-generated.glb이고 가짜 ComfyUI는 /__product-glb?fixture= 로 상품 GLB를 바꿀 수 있어.
